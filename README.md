# YouTube Auto PiP 1.0.8

Автоматический режим использует Document Picture-in-Picture. Видео временно переносится в отдельное окно и возвращается на исходное место при возврате на YouTube. Внутренний PiP-флаг YouTube не включается.

## Установка

1. Отключите или удалите все старые версии в `chrome://extensions`.
2. Распакуйте ZIP и загрузите папку `YouTube-Auto-PiP-1.0.8`.
3. Полностью обновите вкладку YouTube через `Ctrl+R`.

Кнопка в меню оставлена для проверки обычного нативного PiP. Автоматический режим работает через новый механизм.
